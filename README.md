# Customizing the Blazor Maps Component Data Labels

## Overview

This sample demonstrates data-label customization using the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component in a hosted Blazor WebAssembly application. The implementation shows how map data labels can be displayed, formatted, and arranged to improve readability when visualizing geographic information. The sample also demonstrates custom label rendering and intelligent label placement techniques that help prevent overlapping labels while maintaining clear presentation of region-specific data.

**Examples**: https://blazor.syncfusion.com/demos/maps/data-labels?theme=bootstrap5

**Documentation**: https://blazor.syncfusion.com/documentation/maps/data-labels 

## Key Features

- Demonstrates rendering data labels on map shapes using the Maps data-label feature.
- Shows how label text can be formatted for improved readability and presentation.
- Demonstrates intelligent label arrangement to reduce overlap between labels.
- Illustrates custom label rendering for displaying additional contextual information.
- Uses map data labels to present shape-specific information directly on the map surface.
- Demonstrates geographic visualization enhanced through label placement and formatting.
- Shows label-based data presentation without requiring tooltip interaction.
- Uses the implementation hosted in `Client/Pages/Index.razor` as the primary sample page.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `CustomDataLabels.sln`

3. Restore NuGet packages.
4. Set the startup project 
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```
